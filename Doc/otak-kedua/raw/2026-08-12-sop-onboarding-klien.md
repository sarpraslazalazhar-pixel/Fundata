# SOP Onboarding Klien Baru

**Versi:** 1.0
**Tanggal Efektif:** 1 Agustus 2026
**Pemilik Proses:** Account Manager
**Disetujui oleh:** Direktur Operasional

---

## 1. Tujuan

Memastikan setiap klien baru mendapatkan pengalaman onboarding yang konsisten, profesional, dan efisien. Proses ini bertujuan untuk membangun hubungan yang kuat sejak awal, mengumpulkan informasi penting untuk eksekusi proyek, dan menetapkan ekspektasi yang jelas.

## 2. Ruang Lingkup

SOP ini berlaku untuk semua klien baru yang telah menandatangani kontrak kerja sama, mencakup:
- Klien proyek (project-based)
- Klien retainer (monthly/quarterly)
- Klien dengan kontrak khusus

## 3. Definisi

| Istilah | Definisi |
|---------|----------|
| **Account Manager (AM)** | Orang yang bertanggung jawab mengelola hubungan dengan klien |
| **Brief** | Dokumen yang berisi kebutuhan dan tujuan proyek dari klien |
| **Kick-off Meeting** | Pertemuan pertama dengan klien untuk memulai proyek |
| **SLA** | Service Level Agreement - kesepakatan tingkat layanan |

## 4. Prosedur

### 4.1 Fase Persiapan (Hari H-3 s/d H-1)

**PIC:** Account Manager

1. Membuat folder klien di Google Drive dengan struktur:
   ```
   /[Nama Klien]
   ├── 01_Brief
   ├── 02_Kontrak
   ├── 03_Aset
   ├── 04_Deliverable
   └── 05_Komunikasi
   ```

2. Menyiapkan dokumen briefing menggunakan template standar

3. Mengirim email selamat datang dengan lampiran:
   - Company profile
   - Portofolio relevan
   - Questionnaire awal

4. Menjadwalkan kick-off meeting dan mengirim kalender invite

### 4.2 Fase Kick-off Meeting (Hari H)

**PIC:** Account Manager + Tim Kreatif

**Peserta wajib:**
- Account Manager
- Project Manager
- Klien (decision maker)

**Agenda:**
1. Perkenalan tim (10 menit)
2. Review brief dan klarifikasi (20 menit)
3. Diskusi timeline dan milestone (15 menit)
4. Penetapan komunikasi protocol (10 menit)
5. Q&A (5 menit)

**Output:**
- Minutes of Meeting (MoM)
- Project timeline draft
- Communication plan

### 4.3 Fase Follow-up (Hari H+1 s/d H+3)

**PIC:** Account Manager

1. Mengirim MoM dalam waktu 24 jam setelah meeting

2. Meminta konfirmasi dan revisi (jika ada) dari klien

3. Finalisasi timeline dan kirim untuk approval

4. Setup channel komunikasi:
   - Grup WhatsApp/Telegram untuk komunikasi harian
   - Email untuk dokumen formal
   - Notion/Trello untuk tracking proyek

### 4.4 Fase Handover ke Tim Internal (Hari H+3)

**PIC:** Account Manager → Project Manager

1. Briefing internal dengan tim eksekusi

2. Review scope dan deliverables

3. Penetapan PIC per deliverable

4. Setup project di tools manajemen:
   - Notion untuk dokumentasi
   - Trello/Jira untuk task management
   - Google Calendar untuk deadline

## 6. Metrics dan KPI

| Metric | Target | Frekuensi Review |
|--------|--------|------------------|
| Client Satisfaction Score (post-onboarding) | ≥ 4.5/5 | Setiap klien baru |
| Waktu onboarding | ≤ 5 hari kerja | Bulanan |
| Response time awal | ≤ 2 jam | Setiap klien |
| MoM delivery | ≤ 24 jam | Setiap kick-off |

## 7. Penanganan Eksepsi

### 7.1 Klien meminta revisi berulang pada brief
- AM mengadakan meeting khusus untuk klarifikasi
- Jika tidak ada kejelasan dalam 2 meeting, eskalasi ke Direktur

### 7.2 Klien tidak responsif
- Follow-up via telepon setelah email tidak dijawab 2x
- Eskalasi ke level atas klien jika tidak responsif dalam 3 hari

### 7.3 Perubahan scope saat onboarding
- Dokumentasikan sebagai change request
- Update kontrak jika perlu
- Komunikasikan impact ke timeline dan budget
